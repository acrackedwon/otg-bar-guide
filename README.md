# ON THE GROUND — 직원 가이드

매장 내부용 가이드 사이트. 칵테일 레시피와 운영 절차를 직원들이 폰에서 바로 열어 보는 용도.

- **콘텐츠 저장소: 노션** — 사장님이 폰 노션 앱에서 글을 쓰고 사진을 올리면 사이트에 바로 반영됩니다. 개발자를 거칠 필요 없습니다.
- **접근 권한: 사이트 전체 공용 비밀번호** — 직원 모두가 같은 암호를 씁니다.
- **영상: 구조만 준비** — 영상은 `{제공자, 영상ID}` 형태로만 저장하므로, 유튜브 비공개로 시작했다가 나중에 Cloudflare Stream 등으로 바꿀 때 `src/video.ts` 한 곳만 고치면 됩니다.

기술 스택은 손님용 사이트(`otg-bar`)와 같은 계열입니다: TypeScript + Vite, React·Tailwind 없음. 배포는 Vercel.

---

## 1. 노션 준비 (최초 1회)

1. 노션에서 **데이터베이스(표)** 를 새로 만듭니다. 이름은 자유롭게 (예: `OTG 가이드`).
2. 아래 속성을 **이름 그대로** 만듭니다. 이름이 다르면 사이트가 못 읽습니다.

   | 속성 이름 | 종류 | 설명 |
   |---|---|---|
   | `제목` | 제목(Title) | 항목 이름. 예: `네그로니` |
   | `분류` | 선택(Select) | 상단 탭이 됩니다. 예: `칵테일`, `운영` |
   | `요약` | 텍스트(Text) | 목록에 한 줄로 보이는 설명 |
   | `순서` | 숫자(Number) | 작을수록 위에 표시 (비우면 맨 뒤) |
   | `영상` | URL | 유튜브 링크를 그대로 붙여넣으면 됩니다 |
   | `공개` | 체크박스 | 체크 해제하면 사이트에 안 보입니다 (작성 중인 글) |

3. 각 항목을 열어 **본문에** 내용을 씁니다. 사이트가 읽어오는 본문 요소: 제목(H1~H3), 문단, 글머리 기호 목록, 번호 목록, 할 일 목록, 인용, **이미지**.
4. 노션 → 설정 → **연결(Integrations)** 에서 내부 통합을 하나 만들고 **토큰(secret)** 을 복사합니다.
5. 만든 데이터베이스 페이지에서 우측 상단 `⋯` → **연결 추가** → 방금 만든 통합을 선택합니다. (이걸 빠뜨리면 권한 오류가 납니다.)
6. 데이터베이스 URL에서 **데이터베이스 ID** 를 복사합니다 — `notion.so/<워크스페이스>/<여기가_ID>?v=...` 의 32자리 부분.

## 2. Vercel 환경 변수

Vercel 프로젝트 → Settings → Environment Variables에 4개를 넣습니다.

| 이름 | 값 |
|---|---|
| `SITE_PASSWORD` | 직원들에게 알려줄 사이트 비밀번호 |
| `SESSION_SECRET` | 아무 긴 랜덤 문자열 (로그인 쿠키 서명용) |
| `NOTION_TOKEN` | 1-4에서 복사한 통합 토큰 |
| `NOTION_DATABASE_ID` | 1-6에서 복사한 ID |

`SITE_PASSWORD`를 비워두면 비밀번호 없이 누구나 들어옵니다. 반드시 설정하세요.
`NOTION_TOKEN` / `NOTION_DATABASE_ID`가 비어 있으면 사이트는 예시 콘텐츠로 동작합니다 — 연동 전에도 화면을 볼 수 있습니다.

## 3. 영상 추가

지금은 `영상` 칸에 **유튜브 링크를 붙여넣으면** 됩니다. 유튜브에 올릴 때:

- 공개 범위를 **일부 공개(Unlisted)** 로 설정 — 링크를 아는 사람만 볼 수 있습니다. (완전한 비공개는 아닙니다.)
- 촬영은 **30초~1분 단위로 짧게, 1080p** 로. 4K로 길게 찍으면 파일이 커지고 편집·업로드가 번거롭습니다.

나중에 Cloudflare Stream 등으로 옮길 때는 `src/video.ts`의 `embedUrl()`만 고치면 됩니다. 영상은 코드 어디에도 파일로 저장되지 않습니다.

## 4. 로컬 개발

```bash
npm install
npm run dev      # 프런트엔드만 (API 없이 로그인 화면에서 막힘)
npx vercel dev   # API 포함 전체 동작 — .env.local 에 환경 변수 필요
```

`.env.example`을 `.env.local`로 복사해 값을 채우세요.

## 5. 구조

```
index.html          진입점
src/main.ts         화면 전체 (로그인 → 탭 목록 → 상세)
src/video.ts        {제공자, 영상ID} → 임베드 URL. 영상 제공자 교체 지점
src/styles.css      스타일 (모바일 우선, 다크)
api/login.ts        비밀번호 확인 후 세션 쿠키 발급
api/logout.ts       세션 해제
api/content.ts      세션 확인 후 노션 콘텐츠 반환
lib/auth.ts         쿠키 서명·검증
lib/notion.ts       노션 → 사이트 데이터 변환 (속성 이름은 파일 상단 PROP)
lib/content.ts      타입 정의, 영상 링크 파싱, 예시 콘텐츠
```

### 보안 수준에 대해

비밀번호는 서버(Vercel 함수)에서 확인하고, 콘텐츠도 로그인한 브라우저에만 내려갑니다. 정적 파일에 레시피가 박혀 있는 방식보다 안전합니다. 다만 **직원 한 명이 암호를 외부에 알려주면 막을 방법이 없습니다** — 누가 봤는지 추적이 필요해지면 직원별 로그인으로 바꿔야 합니다.
