# 사진 넣는 곳

이 폴더에 사진을 올리면 사이트에서 `/photos/파일이름.jpg` 로 불러옵니다.

## 폰이나 컴퓨터에서 올리는 법

1. [github.com/acrackedwon/otg-bar-guide](https://github.com/acrackedwon/otg-bar-guide) 접속
2. `public` → `photos` 폴더로 들어가기
3. 우측 상단 **Add file → Upload files**
4. 사진을 끌어다 놓거나 선택 (여러 장 한 번에 가능)
5. 맨 아래 **Commit changes**

파일 이름은 영문으로 짓는 게 안전합니다. 한글 이름도 되지만 주소가 지저분해집니다.

예: `cass-crate.jpg`, `gas-valve.jpg`, `wine-cellar.jpg`

## 올린 뒤

어느 항목에 넣을 사진인지 말씀해 주시면 본문에 걸겠습니다.
직접 넣으시려면 글 안에 이렇게 씁니다:

```
![카스 병 컨테이너](/photos/cass-crate.jpg)
```

## 알아둘 것

- **이 폴더의 사진은 비밀번호 없이도 주소를 알면 볼 수 있습니다.** 사이트 본문은
  비밀번호로 막히지만 사진 파일 자체는 정적으로 서비스되기 때문입니다.
  매장 내부 사진이라 큰 문제는 아니지만, 민감한 것(서류, 금고, 개인정보)은 올리지 마세요.
- 사진이 너무 크면 폰에서 느립니다. 한 장에 **500KB 이하**가 적당합니다.
  그냥 올려주셔도 됩니다 — 큰 파일은 제가 줄여서 다시 커밋하겠습니다.
